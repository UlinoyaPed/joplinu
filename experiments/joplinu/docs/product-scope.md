# JoplinU 产品范围

2026-10-29 用户明确：目标是覆盖 Joplin 绝大部分功能，并优化编辑体验；不要求兼容原版，内部方案允许改进。原型目录是当前工程位置，不代表产品只做原型。现有用户数据、安全和必要许可证继续保护。

接下来继续补数据层与文档服务，再连接安全凭据和同步；编辑器体验可并行逐步完善。避免为旧架构兼容、字节级排版保留或品牌兼容声明消耗主要开发时间。数据不丢失仍是验收条件，真机表现必须单独实测。

## 本批已实现

- 源码、实时预览、双列共用格式工具：加粗、斜体、删除线、行内代码、标题、列表、引用、任务、代码块、表格、链接与公式；Ctrl/Cmd+B、I、Shift+X、K；查找替换入口与中文面板。
- 格式操作作用于选区 / 所选行，使用一次事务和共享撤销。CodeMirror 保留 CR 字符，使导入 CRLF 时的位置与 Y.Text 一致。
- 待办是笔记元数据，完成 / 取消不改正文任务列表；副本保留类型，作为新的未完成待办。置顶独立保存，不伪造正文编辑时间。
- 标签统一重命名、重名合并、移除标签；处理回收站内标签，不修改正文或历史。
- 条件搜索 `title:`、`body:`、`tag:`（精确标签）、`notebook:`（路径包含）、`type:note|todo`、`is:todo|note|completed|uncompleted|pinned`；双引号短语、`-` 排除、`any:1` 正条件 OR（排除始终生效）。未知操作符按普通文本处理，半输入不抛渲染错误；最长 4000 字符。

只保留关键回归，不以测试数量作为完成指标。当前自动化不能证明真机 IME、完整同步或大容量笔记库已完成。

当前 v2 存储是远端已有改动，本批已接入。v2 使用独立数据库，不自动迁移 v1；旧版本请先导出完整备份，再在 v2 恢复，原 v1 文件不删除。参见 [yjs-journal.md](yjs-journal.md)。
